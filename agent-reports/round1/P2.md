## Assignment

Replace the opaque rectangular dialogue HUD with an original translucent, organically rounded speech bubble in the visual language described by reference A/B: smoky charcoal fill, light organic rim, floating character-colored name tag, large rounded sans type, and an amber continue marker that animates only when the line is complete. Keep the boardroom visible, preserve text/hit areas, support keyboard focus and reduced motion, and avoid regressions to existing vote/factory/archive work.

## What changed in `src/style.css`

Only the dialogue rules and their two responsive overrides were replaced; unrelated CSS is unchanged.

- **Original bubble silhouette:** asymmetric superellipse/speech-lobe `border-radius: 45% 53% 41% 50% / 58% 46% 54% 61%`, not a rounded rectangle. A `3px` light border at desktop (`2px` on narrow screens), no rectangular edge.
- **Translucency:** layered charcoal/espresso gradient at roughly `rgba(43,38,39,.74)` → `rgba(21,18,20,.81)`, warm inner sheen, only `2.5px` backdrop blur. Boardroom remains visible.
- **Floating name tag:** absolute oval over the top-left rim; color derived from P1's `--speaker-color` plus a low-opacity `--speaker-accent` highlight; cream `#fff8ee` bold text. Tags are muted mauve/coral/sage/grey according to the speaker. No monogram, species, role, phase label, or progress text.
- **Type:** local-only rounded sans stack (`"Trebuchet MS", "Segoe UI Variable Display", "Segoe UI", ui-rounded, system-ui, sans-serif`), weight 600. Measured `34px / 44.54px` at 1920×1080, `24.86px / 32.57px` at 1366×768, `24px / 31.44px` at 1024×768, `20px / 26.8px` at 390×844. Line-height 1.31. No serif, no external font.
- **Continue marker:** small amber teardrop (`17×20px`) at bottom center. It is dim (`opacity .36`, no animation) during `.is-typing` and pulses only under `.is-complete`. The real button is `46×46px` with a 3px gold `:focus-visible` ring. The full bubble remains pointer-operable.
- **Shortcut hint:** `.dialogue-shortcut` is a discreet low-contrast “Click / Space” outside the bubble's bottom-right edge; hidden below 850px.
- **Layout:** centered, lower part of the frame, `78vw` capped at `1380px`; content-driven height. No horizontal or text overflow at 1920×1080, 1366×768, or 1024×768.
- **Motion:** 220ms scale/fade entry with transform/opacity only (no layout reflow); 240ms subtle name-tag settle on typing; 210ms scale/fade exit driven by P1's `.is-leaving` hook. `prefers-reduced-motion` collapses animation/transition durations to ~0.001ms and P1 hides instantly.
- **Removed old HUD CSS:** `.dialogue-speaker`, `.speaker-ring`, `.speaker-species`, `.dialogue-heading`, `.speaker-role`, `.dialogue-phase-label`, `.dialogue-progress`, the old caret, and their responsive rules are gone. Browser check found **0** legacy HUD nodes.

## Remaining risks / caveats

1. **Real-time exit capture:** the 210ms fade was verified by computed transition timing plus a slowed inspection because headless Chromium was frame-starved. A physical browser at normal frame rate should show the intended 210ms fade; I have not captured that in real time.
2. **Physical projector legibility** at 3–4m is unmeasured. CSS sizes and composited contrast are measured; the 16px name tag at 1366 is the smallest presenter-facing label.
3. **Contrast sampling** covers the captured 2005 boardroom scenes, not every possible camera/scene lighting state; the translucent layer is intentionally ~0.74–0.81 alpha, and the measured worst case remains comfortably above AA.
4. **Synthetic keyboard timing:** in the loaded headless session, a synthetic `Space` press took 0.7–1.8s to reach the page, after the ~0.5s reveal, so I did not independently capture “press while still typing” (the actual `.is-typing` state and marker styling were verified). P1 separately reports the skip-then-advance and 160ms double-input guard tests as passing.
5. **Per-line motion:** the name tag does a very small settle animation whenever a line starts (`is-typing`). It is not gated to speaker changes because the contract has no speaker-change class; it is subtle (≤2px, 240ms) and honors reduced motion. If this is judged too frequent, the animation can be removed without layout impact.
6. The blur is deliberately light (2.5px) for readability and cost. Low-end GPU performance has not been profiled separately; the bubble is DOM-only and scaled.
7. No external fonts, images, CDNs, or new assets were added.
